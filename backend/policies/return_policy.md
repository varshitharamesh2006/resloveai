# Return Policy

## Eligibility Window
- Most items can be returned within **30 days** of the delivery date.
- Items marked as "Final Sale" or "Personal Care" (earbuds, innerwear, opened cosmetics) are **not eligible** for return.
- The item must be unused, in original packaging, with tags/labels intact, unless the return reason is "defective" or "wrong item received".

## Return Reasons and Handling

### Defective / Damaged on arrival
Full return window is extended to 45 days. Prepaid return shipping label is provided automatically. No questions asked.

### Wrong item received
Full return window is extended to 45 days. Prepaid return shipping label is provided automatically.

### No longer needed / changed mind
Standard 30-day window applies. Customer pays return shipping unless they are a Gold loyalty tier member, in which case return shipping is free.

### Size/fit issue (apparel/footwear)
30-day window, free exchange, free return shipping.

## Process
1. Confirm the order is delivered and within the eligible window.
2. Confirm the item is not on the excluded list.
3. Create a return request with a reason code.
4. Generate a return shipping label if applicable.
5. Refund is issued once the returned item is received and inspected (see Refund Policy), UNLESS the reason is "defective" or "wrong item", in which case refund can be issued immediately upon return creation.
